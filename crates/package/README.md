# µcad package API

[![Crates.io](https://img.shields.io/crates/v/microcad-package.svg)](https://crates.io/crates/microcad-package)
[![Documentation](https://docs.rs/microcad-package/badge.svg)](https://docs.rs/microcad-package/)

This crate provides the µcad package Rust API which provides data structures for access and calling workbenches and functions inside microcad libraries.

A package consists of:

* A library represented as a resolved symbol tree (RST).
* A manifest file `mu.toml` containing metadata, a list of dependencies to other packages.
* Examples
* Documentation as markdown
